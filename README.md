# 🧩 Sentence Structure

One of the most important A1 topics is basic German word order.

### Basic Statement

```text
Subject + Verb + Object
```

Example:

```text
Ich lerne Deutsch.
```

> I learn German.

### Yes/No Question

```text
Verb + Subject + Object?
```

Example:

```text
Lernst du Deutsch?
```

> Are you learning German?

### W-Question

```text
W-Word + Verb + Subject + ...?
```

Example:

```text
Wo wohnst du?
```

> Where do you live?

---

# 🔀 Separable Verbs

Separable verbs are important in German A1.

Example:

```text
aufstehen
```

In a normal sentence:

```text
Ich stehe um 7 Uhr auf.
```

The prefix **auf-** moves to the end of the sentence.

---

# 🧩 Modal Verbs

Important German A1 modal verbs:

| German      | English                 |
| ----------- | ----------------------- |
| **können**  | can / be able to        |
| **müssen**  | must / have to          |
| **wollen**  | want to                 |
| **sollen**  | should / be supposed to |
| **dürfen**  | may / be allowed to     |
| **möchten** | would like to           |

Basic structure:

```text
Subject + Modal Verb + ... + Infinitive
```

Example:

```text
Ich kann Deutsch sprechen.
```
